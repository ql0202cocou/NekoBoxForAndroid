## 记录规则

- 按主题建立 Markdown 文件；同一主题更新原文件，避免重复记录。
- 文件注明来源或关联提交、当前状态、验证依据和下一步；未验证的判断明确标注。
- 新增、迁移或完成记录时同步更新此索引，保持目录可查。
- 已完成的问题在原记录中更新状态；过期结论及时更正，不追加聊天流水账。
- 按当前任务选择阅读相关记录；历史问题是否仍存在，以当前代码和验证结果为准。
